# 학교 자료 지속 동기화

사용자 요청은 일회성 전체 다운로드가 아니라, 학교 사이트를 계속 확인해 새 자료와 일정 변경을 iCloud 서재에 반영하는 것이다. 사용자는 도서관 앱과 같이 앱 내 웹 로그인과 인증된 직접 요청을 연결하고, GPT 실행 없이 프로그램이 주기 확인과 '지금 확인'을 수행하는 방식을 명시했다. 먼저 만든 GPT heartbeat `plato`는 이 결정에 따라 PAUSED로 전환했다. 직접 동기화 실행기와 앱 버튼은 아직 구현·검증 전이다.

## 인증과 직접 통신 설계

- 앱 내 학교 로그인 웹뷰가 획득한 해당 서비스의 세션 쿠키를 같은 앱의 HTTP 클라이언트와 연동한다. 도서관 세션, 학교 통합 SSO 세션, 학지시 세션, PLATO 세션이 같은 토큰이라고 가정하지 않는다. 브라우저 앱의 기존 로그인 토큰이 다른 앱으로 자동 공유된다고 가정하지 않는다.
- 공식 REST API가 현재 계정에 허용되면 사용한다. 허용되지 않으면 학교 웹 서비스가 사용하는 인증된 HTTP 요청/응답을 조사해 구현한다. 재인증·추가 인증 요구는 우회하지 않는다.
- 인증 정보는 iPad Keychain/웹뷰 전용 저장소, 노트북은 해당 사용자 보호 저장소에 유지한다. iCloud 공유 폴더나 GitHub에 토큰/쿠키/비밀번호를 저장하지 않는다. 노트북 실행기는 별도 정상 로그인이 필요할 수 있다.
- 앱 전면의 '지금 확인'은 즉시 직접 요청한다. 앱 종료/백그라운드 상태의 iPad에 정확한 주기 실행을 보장하지 않는다. 지속적인 주기 확인은 노트북의 독립 실행기를 사용하며 Codex/GPT를 호출하지 않는다. 노트북에 등록할 주기는 30분을 기본값으로 한다.
- 2026-10-20 PLATO 표준 Moodle REST 경로에 인증 정보 없이 요청했을 때 `invalidtoken` 응답을 확인했다. 경로가 존재한다는 증거이며 학생 계정의 API 토큰 발급 권한이나 필요한 함수 사용 가능성이 검증된 것은 아니다.

## 직접 통신 실증 (2026-10-20)

사용자가 학교 로그인을 완료한 세션을 개발 도구로 읽어 메모리에서만 사용했다. 해당 서비스의 같은 출처에만 인증 정보를 보내고, 브라우저 화면 조작 대신 별도의 HTTP 클라이언트로 아래 요청을 실행했다. 쿠키/CSRF 값/비밀번호/뷰어 토큰은 코드나 검증 기록에 저장하지 않았다.

- 학생지원시스템 `/ost/cls/timetablesearch/persontimetablesearch/selectPersonTimetable`: 실제 화면에서 관측한 POST 요청 형식·암호화 본문·CSRF 헤더를 재사용해 HTTP 200과 `data` 배열 14행의 시간표 JSON을 받았다. 화면에 표시된 현재 학기 7개 교과목 코드와 대조했다. 이 실험은 독립 클라이언트가 본문 암호화를 새로 생성하거나 CSRF를 갱신하는 구현까지 검증한 것은 아니다.
- PLATO `/lib/ajax/service.php`의 `core_course_get_enrolled_courses_by_timeline_classification`: MoodleSession과 현재 CSRF sesskey로 HTTP 200, error=false, 등록 강좌 9개를 받았다. 이 중 현재 학기 7과목은 shortname에 학년도/학기 코드와 교과목 코드/분반이 포함돼 학지시와 정확히 대응시킬 수 있다. 별도의 장기 Moodle REST 토큰을 발급한 것이 아니다.
- 경영과학 강의실 전체 주차 페이지를 직접 GET해 파일 자료 6개 ID를 확인했다. PLATO의 ubfile은 사용자 정의 모듈이므로 표준 Moodle API에 모든 내용이 노출된다고 가정하지 않는다. 목록과 과제 상세는 필요하면 직접 받은 HTML을 파싱한다.
- 과제 상세 95456을 직접 GET해 시작 `2026-10-06 00:00:00`, 마감 `2026-11-13 23:59:00`을 확인했다. JSON API만으로 모든 과제를 수집하는 경로는 아직 검증하지 않았다.
- 실제 뷰어가 쓰는 경로를 확인한 뒤 `/local/csmsdoc/download.php`에 자료 ID와 로그인 세션으로 직접 요청했다. HTTP 200, application/pdf, 총 492490바이트를 수신했고 `%PDF-` 헤더와 SHA256 `b2bc07ad0637ecf1421f72691f76c5c78d379810d4a886960b57df9e98770c48`를 검증했다. 실제 파일 다운로드에 GPT, 클릭 자동화 또는 별도 문서 서비스 API 키는 필요하지 않았다.

결론: 인증된 직접 통신 방식으로 구현 가능하다. 아직 남은 구현은 Swift 웹뷰→URLSession 쿠키 연동, 학지시 요청 생성/암호화·CSRF 갱신, 세션 만료 처리, 독립 주기 실행기, iCloud 증분 저장과 '지금 확인' 버튼 연결이다. 아이패드 실기기 인증과 새 학기 전환은 별도 검증이 필요하다.

## 실행 범위

- 초기 조사에서는 CUA 브라우저로 부산대 학생지원시스템과 PLATO의 실제 로그인 상태를 확인했다. 운영 동기화는 GPT/브라우저 조작 대신 위 직접 통신 실행기로 구현한다. 비밀번호를 코드, 이 문서, 예약 프롬프트, 동기화 기록에 저장하지 않는다. 인증이 필요하면 사용자에게 요청하고 기존 자료는 유지한다.
- 학생지원시스템의 현재 학년도/학기, 개인시간표, 교과목 코드와 분반을 읽는다. PLATO의 현재 학기 교과과정 강좌와 정확히 대응시킨다. 학기, 과목, 강좌 ID를 고정하지 않는다. 이름만으로 모호하게 대응시키지 않는다. 자율강좌는 자동 수집 대상에서 제외한다.
- PLATO 각 강좌의 전체 주차 목록에서 제공된 수업자료와 과제 일정/첨부를 확인한다. 파일, 폴더, 강좌 공지의 실제 첨부를 대상으로 한다. 동영상은 재생하거나 다운로드하지 않는다. 과제를 제출하거나 출석/수강신청/성적/학교 계정 설정을 변경하지 않는다.

## iCloud 저장과 중복 방지

서재 루트는 `config/library.local.json`의 root를 읽는다. 기존 경로를 추측하거나 다른 개인 폴더를 변경하지 않는다. 파일은 `학기/과목명 [분반]/강의자료/`에 저장하고, 과제 목록은 해당 과목의 `과제일정.md`와 `.inkdrive/campus.json`에 기록한다. 시간표는 학기 폴더의 `시간표.json`에 저장한다. 시간표의 수업 길이와 표의 예약 시간 구간은 별도로 기록하며 75분 수업을 임의로 90분 수업으로 바꾸지 않는다.

`.inkdrive/campus-sync-state.json`에 스키마 버전, 최근 성공 시각, 학기, 과목 코드/분반, PLATO 강좌 ID, 원본 페이지 URL, 자료/과제 ID, 페이지에서 확인한 수정 정보, 저장 경로, SHA256, 성공/실패 상태를 기록한다. 인증 토큰/쿠키/비밀번호는 기록하지 않는다. 기록은 임시 파일을 작성한 뒤 교체한다. 전체 동기화 잠금으로 중복 실행을 막는다.

매번 페이지 목록을 다시 확인하지만 이미 성공 처리한 같은 자료는 다시 받지 않는다. 신규 자료 또는 사이트에서 확인되는 수정 정보가 달라진 자료만 받는다. 사이트에 수정 정보가 없으면 동일 URL의 내용 변경까지 탐지했다고 주장하지 않는다. 최초 실행은 현재 자료 목록을 기준선으로 저장하고 이후 신규 자료부터 처리한다. 최초 실행에 과거 자료 전체를 소급 다운로드하지 않는다.

다운로드는 사이트에서 확인된 파일 경로로 인증된 HTTP 클라이언트가 수행한다. 내려받은 파일의 존재, 크기와 SHA256을 확인하고 로그인 HTML/오류 페이지를 자료로 저장하지 않는다. 파일명에서 경로 구분자, `..`, Windows 예약 이름을 정리하고 서재 내부 경로인지 확인한다. 같은 이름의 기존 파일이 있으면 덮어쓰지 않고 자료 ID/해시를 붙인 별도 파일로 보존한다. 기존 필기, 녹음, 사용자 파일은 삭제하거나 덮어쓰지 않는다. 실패한 항목을 완료 처리하지 않는다.

한 번에 처리량이 많으면 제한된 묶음으로 진행하고 다음 실행에서 이어간다. 다른 학기로 전환되거나 수강 취소된 과목도 과거 폴더와 필기를 그대로 보존한다. 노트북이 꺼진 사이의 자료는 다음 성공 실행에서 목록을 다시 비교해 찾는다. 예약 시간이 지나자마자 자동으로 추격 실행된다고 보장하지 않는다.

## 현재 검증 범위

2026-10-20 사용자가 학교 인증을 완료한 뒤 학생지원시스템의 2026학년도 2학기 7과목 및 주간 시간표, PLATO 동일 7과목 강의실, 산업데이터과학과 경영과학의 전체 주차 자료 목록을 실제 화면에서 확인했다. 지속 예약의 첫 실행, 새 파일 발생 후 다운로드, 다음 학기 전환은 아직 실증하지 않았다. 기존 밤 22시 AI 정리 예약은 별개이며 이번 자료 동기화 작업에서 상태를 바꾸지 않는다.
