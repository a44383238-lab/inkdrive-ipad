# 학교 자료 지속 동기화

2026-10-21 현재 구현 기록. 이전의 수집 예정/최초 기준선만 보관하는 계획은 아래 실제 동작으로 대체했다.

## 현재 동작

- iPad 학교 화면의 WKWebView와 Windows 전용 WebView2에서 로그인한다. 각 앱이 자기 로그인 저장소의 쿠키를 직접 HTTP 클라이언트에 연결한다. GPT로 페이지를 읽거나 다운로드하지 않는다.
- PLATO의 현재 세션 AJAX로 전체 수강목록을 읽고, 매번 과목 shortname에서 학기/과목코드/분반을 구한다. 최신 정규 학기를 고르며 자율강좌는 제외한다. 다음 학기 실제 응답은 아직 검증하지 않았다.
- `학기/과목명_과목코드_분반/강의자료`와 `일정`을 자동 생성한다. 화면에는 학기와 과목명/분반을 표시한다. 최초 현재 학기 자료를 내려받고, 이후 새 자료와 내용 변경을 비교한다.
- ubfile, resource, folder, 과제/페이지/공지 첨부를 확인한다. 외부 수업 URL은 학교 링크로 보관한다. 외부 사이트에 학교 인증 쿠키를 보내지 않는다. 사이트 아이콘/강좌 표지/사용자 아이콘은 첨부에서 제외한다. 수업 동영상은 받지 않는다.
- 첨부는 자료 ID와 SHA256을 포함한 이름으로 보관한다. 기존 필기/원본은 덮어쓰거나 삭제하지 않는다. 변경된 자료는 새 파일이다. 같은 자료에 대한 수정 정보가 없으면 자동 확인 시 하루에 한 번 다시 해시를 검사하고, 수동 확인은 즉시 검사한다.
- 완료한 첨부마다 기기별 `.inkdrive/campus/devices/<device>.json`에 체크포인트를 남긴다. 파일 중단/실패를 완료 처리하지 않으며 나머지를 이어간다. 실패가 있으면 전체 성공 시각은 갱신하지 않는다. iCloud의 순간 파일 잠금은 제한해서 재시도한다.
- iPad 전면 활성 상태는 30분, 저전력 상태는 60분, Windows 앱 실행 중에는 30분마다 확인한다. 재연결과 `지금 확인`도 직접 요청한다. 종료된 iPad의 정시 실행은 보장하지 않는다.

## 인증

비밀번호는 앱/공유 폴더/GitHub에 저장하지 않는다. Windows 세션은 사용자별 DPAPI로 암호화한 로컬 파일과 전용 WebView2 저장소에 유지한다. 프로세스 간에는 익명 stdin/stdout pipe를 사용한다. 로그아웃 시 쿠키와 보호된 세션 파일을 제거한다. 학교가 만료한 인증은 재인증이 필요하다.

같은 학생 ID여도 PLATO 쿠키, 학지시 쿠키, 통합 SSO 증명은 서로 다르다. [학교 공식 안내](https://uitc.pusan.ac.kr/uitc/12077/subview.do)에는 SSO LINK/스마트캠퍼스에서 PLATO로 접속하는 경로가 있다. 목표는 통합로그인 한 번 후 서비스별 세션을 자동 발급하는 것이다. **현재 PLATO 직접 로그인만으로 학지시 세션이 발급되지는 않았다.** 실제 통합인증 이후의 연결 검증은 미완료다. 이전 도서관 앱의 웹/API 연결은 도서관 서비스 안에서의 세션 정합화이며 부산대 모든 서비스의 공통 토큰이라는 뜻이 아니다.

학지시 시간표는 현재 페이지의 RSA/CSRF, 메뉴 권한값으로 요청하는 Swift/Node 구현과 authenticated main HTML 보조 경로가 있다. 암호화 요청 생성 단위 테스트는 통과했지만 실제 계정으로 새 요청을 생성하는 최종 검증은 학지시 인증 후 해야 한다. 과제 상세 원문은 저장하며, 마감을 정규화한 통합 달력은 아직 완료하지 않았다.

## 실제 검증

2026-10-21 Windows InkDrive 전용 로그인 후 현재 2026년 2학기 7과목, 파일 93개, 총 414,996,656 bytes 수집 완료. 93개 모두 저장된 SHA256과 재대조했다. 실제 PPTX 두 개는 101장/83장 미리보기로 생성했다. 한글 파일명과 긴 이름의 확장자, 불필요한 사이트 아이콘을 고쳤다. 첫 수집의 사이트 아이콘 35개와 이전 상태/이름 복구 기록은 `.inkdrive/campus/import-recovery-20261021`에 보존했다.

신규/동일/수정 파일, 학기 전환, 세션 만료, 끊긴 다운로드, 실패 항목 이후 수집 및 재시도는 자동 테스트로 확인했다. 미래의 실제 새 업로드와 다음 학기, iPad 설치 후 인증/자동 수집은 별도 검증이다. 현재 PAUSED인 Codex 수집 예약은 켜지 않았다.
