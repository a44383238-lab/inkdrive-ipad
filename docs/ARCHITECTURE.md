# 작동 계약

## 핵심

- iCloud Drive 폴더는 시스템 폴더 선택기로 선택한다. 보안 범위 북마크를 앱 로컬 설정에 보관하고, 모든 읽기/쓰기 동안 해당 범위를 유지한다.
- 독립 PDF도 시스템 파일 선택기의 `asCopy: false`로 연다. 앱 전용 PDF 복사본이나 별도 필기 파일을 만들지 않는다.
- iCloud 전용 앱 컨테이너가 아니라 사용자가 고른 기존 iCloud Drive 폴더를 사용하므로 개인 iCloud 컨테이너 식별자를 임의로 발급하지 않는다.
- 파일 쓰기는 NSFileCoordinator 쓰기 구간에서 현재 SHA256과 열었을 때의 SHA256을 비교한 다음 원자적으로 교체한다. 충돌·권한 오류 때 기존 원본을 덮어쓰지 않는다.
- 로컬 저장 성공과 iCloud 업로드 완료를 구분한다. UI는 '원본 저장됨 · 클라우드 동기화는 iCloud에서 처리'로 표시한다. Windows 도착 완료를 앱이 단정하지 않는다.
- 수업 종료 때 iPad가 PDF·녹음의 SHA256을 인계 목록에 기록한다. Windows의 저녁 처리는 이 값이 맞을 때만 시작해, 메타데이터보다 PDF 동기화가 늦게 도착한 경우 이전 PDF를 분석하지 않는다.

## 필기 / PDF

- PDFKit 페이지 오버레이에 PKCanvasView를 사용한다. PDFKit이 페이지 회전·확대·이동을 담당하고 Pencil만 필기한다.
- PencilKit 원본 drawing과 공개 PDF appearance를 하나의 소유권 표시된 stamp annotation에 함께 넣는다. 이미지 appearance는 최대 2배, 최대 16M 픽셀로 제한한다. 압력·투명도는 저장 이미지에 반영되며 원본 drawing은 재편집에 사용한다. 벡터 잉크 export는 후속 과제다.
- 원본의 타 앱 주석은 그대로 둔다. 앱 소유 필기 주석만 화면에서 제거하고 live canvas로 대체한다. 저장 복제본에 주석을 다시 넣으므로 중복 표시를 피한다.
- 공개 PDF appearance는 Windows PDF 뷰어를 위한 저장 표현이다. 호환성은 실제 Windows PDF 뷰어에서 아직 검증되지 않았다.
- 페이지 모델에 고유 ID를 부여해 페이지 재정렬과 실행 취소 때 필기 연결이 유지되게 한다.
- 올가미는 앱의 획 선택기로 구현한다. 획 이동·배율·복사·잘라내기·붙여넣기·색상·굵기 변경을 같은 undo history에 기록한다.
- 텍스트와 도형은 표준 PDF 주석으로 저장한다. 텍스트는 생성/수정/이동/크기 조절/삭제를 지원한다.

## 생명주기

1. 파일을 coordinated read로 읽고 암호화·서명 PDF를 확인한다. 서명 보존을 보장할 수 없어 서명 양식 PDF 편집은 차단한다.
2. 한 편집 세션에서만 PDF 객체에 접근한다. 디스크 I/O는 전용 직렬 큐에서 수행한다.
3. 편집 900ms 뒤 저장 예약. 이미 저장 중이면 다음 변경은 dirty 상태를 유지하고 이어서 저장한다.
4. 저장 전 snapshot 생성 실패·파일 충돌은 오류로 표시하고 편집 메모리를 보존한다.
5. 닫기 전에 저장을 기다린다. 실패하면 편집기를 닫지 않는다. 앱 백그라운드 진입 때 제한된 background task 안에서 저장한다.
6. 편집 중 외부 버전 발견 시 자동 덮어쓰기하지 않는다. 사용자가 명시적으로 '외부 버전 다시 열기'를 선택하면 미저장 편집 폐기를 확인한다.

강제 종료·기기 전원 차단 직전의 미저장 변경까지 보장하지 않는다. 900ms 저장 대기 및 iOS background time limit은 남는다.

## 파일과 결과

서재에는 원본 PDF, `Recordings/` 녹음, `.inkdrive/lessons/` 수업 연결 메타데이터, `AI/날짜/작업ID/` 결과가 있다. `.inkdrive`는 필기 보관용 복제본이 아니라 자동 처리용 색인이다. 일반 서재 목록은 PDF/Markdown/TXT를 열 수 있다. Markdown 미리보기는 원문 텍스트이며 수식 조판은 생성된 PDF에서 확인한다.

플렉슬 영상 자체를 이번 작업에서 다시 분석하지 않았으므로 현재 구현은 합의된 기능 목록 기준이다. 자동 도형 인식, 플렉슬과 같은 세부 팝업·필압 튜닝·선택 핸들 동작, 타 앱 주석의 전체 편집 호환성은 동등성을 검증하지 않았다.
