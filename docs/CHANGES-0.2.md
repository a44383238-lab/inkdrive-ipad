# InkDrive 0.2

## 사용 동작

- Pencil 전용 필기와 손가락 페이지 이동을 분리했다. PDF 주석 입력을 활성화하고 손바닥 터치가 Pencil 입력을 막던 조건을 제거했다.
- 한 열로 페이지를 위아래로 이동한다. 놓은 위치를 스크롤 목표로 사용하고 탄성과 관성을 중단한다.
- 필기 도구막대는 56 높이의 아이콘 한 줄이다. 같은 도구를 다시 누르면 해당 위치에 색상·굵기(px)·불투명도 설정이 열린다.
- 펜·연필·형광펜·지우개·올가미·텍스트만 제공한다. 도구 추가·숨김 상태를 기억하고 아이콘에 도구 색상을 반영한다.
- 서재는 폴더 아이콘 격자와 일관된 Lucide 아이콘을 사용한다. 설명 문구를 줄였다.
- 상위 폴더 화살표는 선택한 서재에서 멈춘다. 현재 위치를 다시 누를 때 목록이 지워지던 문제를 수정했다.
- 서재의 마이크는 새 필기 노트와 수업을 자동 연결해 녹음한다. PDF 카드나 필기 화면의 마이크는 해당 PDF에 바로 연결한다.
- 녹음은 기기에 먼저 기록하고 종료 시 iCloud에 복사·해시 확인한다. 이전 복구 기록과 빈 녹음 시작 실패를 구분한다. 원음은 재생하지 않는다.
- 개발용 클라이언트는 마지막 프로젝트를 다시 열고, 기본 서버 http://172.21.12.168:8081 로 연결을 시도한다. 같은 네트워크·실행 중인 서버가 필요하다. 주소가 바뀌면 연결 QR을 갱신해야 한다.

## 검증

- 앱 소스 커밋: 9116211.
- Expo 무료 계정에서 빌드 완료: d9d9e11d-04ed-4dd3-9374-0a9312a95c5d.
- Xcode26.6, 실제 iOS 기기용 arm64 Debug 컴파일 및 IPA 패키징 성공.
- JavaScript 동작 검사20개, TypeScript 검사 통과.
- iPad 시뮬레이터 Swift 검사23개(핵심15개·편집기8개) 통과.
- 웹 테스트 자료로 폴더 열기·상위 화살표·동일 루트 재선택 후 목록 유지와 새 디자인을 확인했다. 실제 사용자 iCloud 파일을 시험 자료로 대체하지 않았다.
- 마이크 버튼의 연결·시작 흐름, 로컬 녹음 파일 전송·복구 검증은 포함한다. 실제 iPad의 Pencil 터치와 실제 마이크 음성 수집은 기기에서 추가 확인해야 한다.

GitHub는 계정 결제·사용 한도 오류로 후속 Mac 작업을 시작하지 못했다. 사용자가 승인한 기존 Expo 무료 계정의 맞춤 빌드로 전환했다. 수업 PDF·녹음을 업로드하지 않았고 추가 결제·Apple 유료 멤버십 가입을 진행하지 않았다.
